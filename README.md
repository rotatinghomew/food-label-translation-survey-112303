# 糖标注理解调查的译文等值与补访

当前资料覆盖多语问卷邀请、题序、桥接与预约资料。记录均为合成数据，使用 UTF-8 编码及带列名的 CSV。

## 运行

使用 Python 3.11。分析依赖在 `requirements.txt` 中锁定，本地环境可运行 `python3 -m pip install -r requirements.txt` 安装。在项目根目录查看文件列和记录数，并核对交接格式。

```sh
python3 inspect_inputs.py data
python3 -I scripts/run_tests.py
python3 -I scripts/run_workbench.py run --data data --today 2026-10-14 --out outputs
```

`python -I` 会忽略 PYTHONPATH，所以统一用 `scripts/` 下的包装入口；数据目录始终以参数传入，脚本不依赖当前工作目录。`--today` 是判定"未到允许改期日"的基准日期；新回执落表后对同一目录重跑即可，所有结论从六张表重新推导，不缓存中间结果。

## 调查工作台（`workbench/`）

- `io.py`：读入六张表并做结构校验（回答回指邀请、原版版本与指派一致、桥接资格与 `bridge_p` 自洽、编码合法）；套用撤回与译版停用更正。撤回默认只撤被点名的 response 行，`--withdraw-groups` 可按同 person 同批次整组撤；停用不删历史回答。
- `scales.py`：只用同一人的盲复测配对做锚题等值（Wilson 区间 + 二项检验，全一致小样本走单独通道并保留提示）；"访谈（先看答案）"不进入等值；按无向版本对归并 rounds 里的双向设计，标明实际观察方向、顺序/译版是否可分、结论适用人群（熟练/全体）；非锚题一律标记为不可跨语言比较。
- `estimates.py`：仅用原版回答、按 `1/selection_p` 加权的语言×渠道×概念误解率；缺失与已邀请未答进入高/低估边界，未接触者留在另一邀请框单独报告；只在等值成立的译版间计算跨语言差距，其余输出"尺度未验证"而不是数值。
- `brief.py`：轮次简报，按语言×渠道给出合资格、接触、有效回答、两类误解证据题次、两类缺口，以及撤回影响、停用信息和适用范围。
- `scheduler.py`：席位硬约束（盲复测/访谈互斥、桥接资格、授权、改期锁、停用版）、问题预约与尚可用席位、开放席位的补访候选打分（关键题修复 + 估计摇摆 + 桥接稀缺），并把差距分成"可用于培训分配"与"仅提示待核实"。
- `cli.py` / `report.py`：终端文本与机器可读 JSON（`outputs/workbench.{txt,json}`），JSON 中不可计算值输出为 `null` 而非 `NaN`。

### 判定口径

- 等值状态：Wilson 95% 下限 ≥ 0.80 判"成立"；配对 ≥5 且全一致走全一致通道（备注保留偏低下限）；点估计 < 0.70 判"失败"；其余为"证据不足"。阈值集中在 `scales.py` 顶部。
- 桥接只覆盖熟练读者时，等值与跨语言差距只适用熟练人群；该语言主版若没有本语言受访者的盲测样本（河湾语），其单独估计仍有效，但跨语言差距一律无桥接支撑。
- 先展示答案的访谈回答、训练班主动报名者的答案都不能进入总体估计或补普通客人的空白；估计只认原版回答。

## 记录约定

答项数值 0 表示误解，1 表示正确，空白表示未观察。桥接层是预先声明适用的熟练读者或全体读者，selection_p 是分层抽取概率。题项所测概念见 items，桥接使用同一参与者标识。电话和现场是不同邀请框，邀请标识为轮次内唯一。

- `items.csv` 不同版次的题项和题序，anchor 标出拟用于桥接的共同题。
- `invitations.csv` 邀请总框，invited_at 为空表示未实际邀请。
- `responses.csv` 逐项编码，bridge 区分原版、盲复测和先看答案后访谈。
- `corrections.csv` 回答撤回及问卷停用，target 以 kind 决定含义。
- `appointments.csv` 正在使用和未来可用的复测资源，空 person 表示开放席位。
- `rounds.csv` 问卷复测设计中各偏好语言主版、桥接资格及计划公布时点。
